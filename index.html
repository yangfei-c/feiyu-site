域名与验证

Name.com 注册域名。Cloudflare 提供 DNS、HTTPS 和静态托管。Google Search Console 通过 DNS TXT 记录验证所有权。

本地研发

VS Code、Node.js 和 Git 支撑本地工作区。DeepSeek Harness（dsh）与 dsh-cost-meter、Playwright MCP、Gemini Pro 和 Codex 用于开发、调研与调试。

产品与模型

官网使用原生 HTML、CSS 和 JS。扩展采用 Manifest V3。桌面助手由 Electron 和 electron-builder 支撑。AI 工具支持 DeepSeek 与可配置模型接口。

扩展发布配置

GitHub Actions 用 dorny/paths-filter 检测变更，执行 node --check 和 MV3 校验，再由 chrome-webstore-upload-cli 提交。Chrome Web Store API 使用 Google Cloud OAuth 2.0 授权。

脚本筹备方向

筹备方向包括 ScriptCat、GM_xmlhttpRequest、GM_getValue 状态存储，以及 Hacker News、GitHub Issues 和 Reddit RSS 数据源。
