隐私政策（Privacy Policy）

生效日期：2026 年 11 月 19 日 · 适用于飞羽系列 Chrome 扩展（飞羽 ArXiv 论文伴侣、飞羽 B 站学习助手）及飞羽相关工具

飞羽（Feiyu）尊重您的隐私，所有产品均坚持“最小权限、尽量本地运行”的原则。本隐私政策说明我们的浏览器扩展及相关工具如何处理您的数据。

1. 我们不会收集的数据

  • 我们不会收集、出售、出租或交易您的个人身份信息、日常浏览历史或账号密码。
  • 我们不会在扩展中植入任何第三方广告追踪器或商业统计脚本。

2. 本地存储与 API 密钥安全

您的偏好设置、自定义提示词以及第三方 AI 服务的 API Key 仅保存在您自己浏览器的本地存储（chrome.storage）中，飞羽服务器不会读取或保存您的 API 密钥。

3. 由用户主动触发的网页内容与 AI 请求

仅当您主动点击功能按钮（例如总结视频字幕、翻译论文段落或截图提问）时，当前页面中与该操作相关的文本或截图才会直接从您的浏览器发送至您自行配置的 AI 模型服务商（如 DeepSeek 或 Google Gemini），并受对应服务商的隐私政策约束。

4. 扩展权限说明

  • storage：用于在浏览器本地保存您的配置与偏好设置。
  • activeTab / 指定站点权限：仅在您主动触发扩展功能时，读取当前受支持学术或视频页面的内容。
  • contextMenus：用于在网页右键菜单中提供划词翻译与快捷提问入口。

5. 主动反馈信息

若您通过产品内置的反馈入口主动提交问题或建议，系统仅会发送您填写的反馈文本及基础扩展版本号，以便我们定位并修复问题。

6. 联系我们

如对本隐私政策或数据处理方式有任何疑问，请通过邮件联系我们：support@feiyu.page。
